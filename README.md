# Random Password Generator (HTML, CSS & JavaScript)

A simple password generator. Click a button to get a new 12-character password, then copy it with one click.

🔗 **Try it live:** https://uzi-password-gen.netlify.app/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Random-Password-Generator-JavaScript-Uzi-Solutions

## 🎮 How to Use

1. Click **Generate Password** to get a new password.
2. Click the copy icon on the right side of the box to copy it.
3. Paste it wherever you need it.

## ✨ Features

- ⚡ Generates a new 12-character password on every click
- 🔤 Mixes uppercase letters, lowercase letters, numbers and symbols
- ✅ Every password has at least one of each type
- 📋 Copy button for the password
- 🎨 Clean dark design with a green accent
- 🚫 No libraries or frameworks

## 🔧 Built With

- **HTML5**
- **CSS3** – flexbox, custom colors, simple button styling
- **JavaScript (ES6)** – DOM manipulation, strings, `Math.random()`, `while` loop
